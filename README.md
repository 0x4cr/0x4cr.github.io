# Portafolio de Ciberseguridad | Alejandro Castañeda Reyes

Sitio personal donde documento proyectos, laboratorios y writeups de seguridad ofensiva, con enfoque en Active Directory.

🌐 **Sitio:** https://0x4cr.github.io

## Contenido

- Laboratorios propios de Active Directory vulnerable (con guía para replicarlos)
- Writeups de explotación y post-explotación
- Notas de aprendizaje sobre Windows Server, Kerberos y pentesting

## Proyecto destacado

**Laboratorio AD vulnerable**: Domain Controller con Windows Server 2022 y dos equipos Windows 10, con una cadena de vulnerabilidades encadenadas, construido en VMware y documentado paso a paso para que sea replicable.
